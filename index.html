SECURITY CENTER

Your data stays yours.

The app is designed around least privilege and local-first analysis.

🔐

OAuth, never passwords

When Spotify integration is enabled, authentication happens on Spotify. Your Spotify password is never entered into this app.

Protected
🧩

Minimal permissions

Request only the Spotify scopes needed for analytics, such as top items and recently played data. Email access is not required for analysis.

Least privilege
🧹

Data minimization

For exported history, the analyzer can ignore IP address, user agent and other technical fields and retain only analysis features.

Minimized
🗑

Disconnect & delete

Use disconnect to clear the local session. Imported history can be discarded without sending it to a third party.

User controlled
